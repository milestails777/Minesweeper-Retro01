If you absolutely love Minesweeper—specifically the classic version from Windows 95—but can’t play it on the dreadful Windows 11, 
then this game is just for you! Here you can experience the true charm of the old Minesweeper with the same mechanics as the original. 
This game was also created specifically as a gift for our Tallinn Polytechnic, or more precisely, for our User Design teacher, 
who was the one who came up with the idea for the game in the first place.

So, enjoy the game, and I hope you like our project and the gameplay as a whole!
